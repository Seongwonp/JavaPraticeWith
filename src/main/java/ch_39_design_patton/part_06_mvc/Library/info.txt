메뉴를 선택하세요:

📌 2️⃣ 세부 동작

✅ 도서 등록
•	도서명, 저자명을 입력받아 데이터베이스에 등록

✅ 도서 목록 조회
•	DB에서 도서 목록을 조회하여 도서번호, 도서명, 저자, 대여 여부를 출력

✅ 도서 대여
•	도서번호를 입력받아 대여 처리 (이미 대여 중이면 “이미 대여 중인 도서입니다.” 출력)

✅ 도서 반납
•	도서번호를 입력받아 반납 처리 (대여 중이 아니면 “대여 중인 도서가 아닙니다.” 출력)

✅ 대여 상태 조회
•	도서번호를 입력받아 해당 도서의 대여 상태를 출력
•	도서명을 입력받아 해당 도서의 대여 상태를 출력

BookDTO : bookId, title, author, rented
