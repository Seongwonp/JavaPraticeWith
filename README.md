# ☕ Java Practice – 자바 기초 및 객체지향 실습 저장소

이 저장소는 Java의 기초 문법부터 객체지향 프로그래밍, 컬렉션, 디자인 패턴까지  
단계별로 실습하며 학습한 내용을 정리한 공간입니다.

---

## 💭 회고

이번 자바 실습을 통해 단순한 문법 암기에서 벗어나,  
**객체지향 프로그래밍의 핵심 철학과 구조적 사고**를 몸으로 익힐 수 있었습니다.

특히 `클래스`, `상속`, `인터페이스`, `추상화`를 학습하면서  
단순히 코드를 작성하는 것이 아니라 **역할을 분리하고 책임을 나누는 설계**가 얼마나 중요한지 깨달았습니다.

그 중에서도 **MVC(Model-View-Controller) 구조의 중요성**은 실습을 거듭할수록 더 깊게 체감되었습니다.  
처음에는 단순한 기능 구현에 집중했지만, 점차 코드가 복잡해질수록  
**모델은 데이터와 로직을 담당하고, 뷰는 사용자에게 보여주며, 컨트롤러는 흐름을 제어한다는 구조적 분리**가  
유지보수성과 확장성을 얼마나 높여주는지 직접 경험할 수 있었습니다.

또한 `컬렉션`, `예외 처리`, `디자인 패턴` 등을 배우며  
**자바라는 언어가 단순한 문법 집합이 아니라, 문제 해결을 위한 강력한 도구**라는 점을 실감했습니다.

마지막으로 `z_Test` 폴더에서 시험 대비용 코드를 작성하면서  
그동안 배운 내용을 스스로 정리하고 응용하는 과정이 큰 도움이 되었고,  
단순히 "배웠다"가 아니라 "이제는 쓸 수 있다"는 자신감으로 이어졌습니다.

이 실습은 단순한 과제가 아니라,  
**프로그래밍이라는 사고방식을 내 것으로 만드는 과정**이었습니다.
